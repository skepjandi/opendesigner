# Code of Conduct

This project follows the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## Our standard

Be respectful and constructive. Harassment, discrimination, personal attacks, and publishing others' private information are not acceptable.

## Enforcement

Report violations privately via a [GitHub private security advisory](https://github.com/skepjandi/opendesigner/security/advisories/new) or to the maintainers' contact listed on their GitHub profiles. Maintainers may edit, reject, or remove contributions and ban contributors who violate this code.
